# Contributing

Contributing to this project is open to any Savannah State University student or alumni. To get started, reach out to [board@tigercs.org](mailto:board@tigercs.org) and ask to be added to the team.

By contributing, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to contribute

- All changes go through a pull request — no direct pushes to `main`.
- Every pull request requires a review from someone on the leads team before it can be merged.

See [README.md](README.md) for local setup and development commands.
